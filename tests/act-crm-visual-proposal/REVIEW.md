# ACT CRM visual proposal

30 October 2026. Buyer-specific visual concept, built from the existing ten-section ACT proposal. Plain HTML preserved at `Downloads/ACT-CRM-Proposal/archive/ACT-CRM-Proposal-plain-2026-10-29.html`. The existing PDF and editable Markdown remain the prior plain version; the visual revision is HTML.

## Design decision

Use the current handover to establish recognition, a side-by-side system view to explain the change, then an interactive job record to make version one tangible. Keep scope, investment, delivery and acceptance in the original order. Replace explanatory tables where a visual makes the same idea clearer. Preserve the commercial blanks.

The reference was `http://127.0.0.1:4318/custom-ai-crm-proposal/proposal.html`: inspected its source and retained `qa/act-proposal-demo.png`, and opened its native Chrome page. Its sidebar job walkthrough, restrained blue/navy palette and current-process handovers inform this revision. No claim of testing the reference's live connections.

## Evidence boundaries

Read the existing ACT source notes and proposal brief. This turn did not replay the discovery audio, inspect the production CRM or test external accounts. The UI is a proposed interface with an illustrative job; it is not presented as an actual deployed screen. The handover questions are illustrative, not attributed quotes.

The calculator starts with examples: 60 requests × 30 minutes = 30 hours now; 60 × 12 minutes = 12 hours proposed; difference 18 hours × A$45 = A$810 of staff-time value. These are not ACT findings, cash savings, net ROI or promised delivery results. Inputs are editable, and a worse future workflow remains a negative result. Invalid inputs show no output.

## Release

Local HTML preview only; no client send, CRM change or public publication. Six walkthrough states, staff decision gates, payment separate from acceptance, optional playback, editable workload chart. JavaScript syntax check passed. Browser checks are recorded in the project context after execution.
