Every deal follows the same path: call one finds the pain and its cost, Jarvis designs the solution and the proposal, call two presents it and closes. Watch the sales lessons before your first call.

## Install Module 6 {2 min}

[[pack:sales]]

```prompt Send to Jarvis, with the file attached
Install Module 6, Sales, from the attached file. Add every skill inside, replace any older versions, and don't run anything yet. When you're done, show me what you installed and where we start.
```

> see: Jarvis lists 3 skills and where to start.
> fix: No call booked yet? Install it anyway and read ahead. Jarvis pushes outreach until you have one.

## Set up call recording {10 min}

Jarvis reviews every call, so it needs the recording. Tell everyone on the call it's being recorded.

```prompt Send to Jarvis
Use the call to close playbook. Set up my call recording first.
```

> see: Jarvis confirms how your calls get recorded and sent to it.
> fix: Not sure which tool to use? Jarvis suggests one and walks you through it.

## After call one {10 min}

```prompt Send to Jarvis
Use the call to close playbook. Here's my call with [business].
```

> see: A call brief with the problem, the yearly cost the owner agreed to, and a review with one thing to change.
> fix: Want a person to review it too? Post the recording in your Discord channel.

## Design the solution {10 min}

What to build, who builds it, what it costs to run, and a price check before you quote.

```prompt Send to Jarvis
Use the solution design skill to design the solution for [business].
```

> see: Two to four parts, each tied to a problem, with build cost and running cost.
> fix: Not sure it can be built? Bring it to your weekly technical call before you quote.

## Write the proposal {10 min}

One page, one premium design. Jarvis suggests a price from the problem's yearly cost. You approve it.

```prompt Send to Jarvis
Use the proposal builder skill to write the proposal for [business].
```

> see: A one page proposal and short notes for call two.
> fix: Price feels wrong? Tell Jarvis your number. It checks it still covers the build.
