## Install Module 2 {2 min}

[[pack:offer]]

1. Download the Module 2 file above.

2. In the Jarvis chat, click + and attach it, then send the message below.

```prompt Send to Jarvis, with the file attached
Install Module 2, The Irresistible Offer, from the attached file. Add every skill inside, replace any older versions, and don't run anything yet. When you're done, show me what you installed and where we start.
```

> see: Jarvis lists 4 skills with their versions, and where to start.
> fix: If Jarvis says an earlier module comes first, do that one. Jarvis tells you when to come back.

## Pick your service and niche {5 min} optional

Skip this if you already know what you sell and who to. If not, Jarvis matches the services that sell right now to your background.

```prompt Send to Jarvis
Use the offer menu skill to show me which services fit me.
```

Want proof a service sells before you pick it? You can also ask:

```prompt Send to Jarvis
Use the custom opportunity finder skill to find a gap in [type of business].
```

> see: Up to three services that fit you, each with the buyer, their problem and how you'd deliver it.
> fix: None feel right? Tell Jarvis what you're good at or who you know. It adapts.

## Write your offer {10 min}

Jarvis asks you three things only you can decide: your guarantee, your hours, and which size of business you'll help.

1. Send the message below.

2. Answer Jarvis's questions.

3. Read your six lines. Ask for any change in plain words, for example "make it 45 days".

4. When you're happy, send "Approved."

```prompt Send to Jarvis
Use the offer creation skill to write my offer. Ask me only what you need, then show me the six lines so I can approve them.
```

```prompt When you're happy
Approved.
```

> see: Your offer is saved as approved in your HUD, and Jarvis marks the module done.
> fix: Not sure about the guarantee? Post your six lines in your Discord channel before you approve. We'll review them.
