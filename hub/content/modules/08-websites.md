One pack, three uses. Install it once, any time after your HUD is set up.

1. **Your own agency website.** Credibility and a portfolio. Do it after your landing page is live (Module 3). The landing page stays your sales funnel.

2. **Demo sites for prospects.** A concept site that helps close a deal (Module 6).

3. **Client websites.** Delivering a website you sold (Module 7).

Media costs money. Sites use generated photos (Premium) or short films (Cinematic). Jarvis always shows you the cost and time before it generates anything. Start with Premium.

## Install the Websites pack {2 min}

[[pack:websites]]

1. Download the Websites file above.

2. In the Jarvis chat, click + and attach it, then send the message below.

```prompt Send to Jarvis, with the file attached
Install the Websites pack from the attached file. Add every skill inside, replace any older versions, and don't run anything yet. When you're done, show me what you installed and where we start.
```

> see: Jarvis lists 3 skills: website research, brand guide and premium website.
> fix: Your HUD must be set up first. If Jarvis says so, finish Module 1.

> see: A research brief with sources, three brand directions to pick from, then the site, tested and handed over on the client's own domain.
