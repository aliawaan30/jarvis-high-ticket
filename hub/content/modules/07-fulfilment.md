You have two ways to deliver: build it yourself with Jarvis, or hand it to a developer and keep the margin. Either way, it starts with one build plan.

## Install Module 7 {2 min}

[[pack:fulfilment]]

1. Download the Module 7 file above.

2. In the Jarvis chat, click + and attach it, then send the message below.

```prompt Send to Jarvis, with the file attached
Install Module 7, Fulfilment, from the attached file. Add every skill inside, replace any older versions, and don't run anything yet. When you're done, show me what you installed and where we start.
```

> see: Jarvis lists the scoping agent and where to start.
> fix: No won deal yet? Install it anyway. Jarvis uses it the moment you win one.

## Scope the build {15 min}

One build plan a developer or Jarvis can build from.

```prompt Send to Jarvis
Use the scoping agent skill to scope the build for [client].
```

> see: A build plan with what gets built, in what order, what the client provides, and how it's tested.
> fix: Handing it to a developer? Bring the plan to your weekly technical call first.

## Test, hand over, go live {varies}

Test it the way the client will use it, then hand over.

```prompt Send to Jarvis
Help me test [client]'s build like the client will use it, then plan the handover and go live.
```

> see: A test list, a handover plan, and the client moved to Live in your HUD.
> fix: Something breaks in testing? Send Jarvis a screenshot. Bigger issue, press "I'm stuck".
