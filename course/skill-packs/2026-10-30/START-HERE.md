Each folder contains its current `SKILL.md`. Retain the `references/` folder wherever supplied. Source snapshots are copied unchanged. Individual frontmatter files are also supplied in `individual-upload-files/` for convenient review or upload. Read the related references too; uploading only the entry file does not transfer its linked resources automatically.

## Use and actual status

Upload/install one relevant skill at a time and run it against an approved offer brief. Use the complete folder when the target agent supports folder-based skills. Base44 upload format and access to supporting files must be checked in the target student account. No credentials, account connections, paid tools, renderers or sending permissions are included.

These skills have mixed draft/reference-inspected/local-test status, recorded inside their entry files. The outreach coordinator has passed structural validation only. No package-wide Base44 or student pilot has been completed. Do not translate file availability into integration readiness.

## Not recovered as current standalone skills here

The local video editor, Jarvis installation/runtime, working CRM, live Meta execution, sales-call review and client onboarding are not supplied by these 13 instruction folders. They require their own maintained assets or execution systems. This pack does not recreate or silently invent those missing pieces.

Rejected overnight test offers and client records are excluded. No course lesson content was changed or bundled into the skills.
