# Optional Clay adapter

Clay is the upgrade in the current course direction, not the lean lab dependency. Use it when the member asks, or when measured contact/research coverage, volume or review effort justifies a comparison.

Claude reports official API/CLI/plugin documentation verified in SYSTEM.md v2. This skill package has not exercised those connections. Check current available operations, plan/credits and provider terms before choosing the adapter. The member's Base44 connection is a separate test from using our Codex/Claude plugin.

Map Clay company/person search, enrichment, signals and research to the same CRM account/contact/evidence records. Preserve actual returned provider IDs and provenance. Do not fabricate a public source URL when the data provider supplies no underlying URL. Channel eligibility must still be established under the applicable rules.

Read-only tables are not the CRM's write interface. Keep the custom CRM as the system of record. Where Sequencer launch/pause needs a human UI action, create an explicit task and record pending versus confirmed state. Verify native reply/opt-out behaviour and event access before claiming automatic global stopping.

Compare incremental usable contacts, time saved, actual credits, subscription costs and downstream meetings. Paid enrichment is not permission to message, a guarantee of correct identity or evidence of buyer pain.
