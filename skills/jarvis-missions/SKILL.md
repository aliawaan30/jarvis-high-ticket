# Missions

Version 1, 4 November 2026. People stay when they see progress. Every day should end with something done.

## How a mission works
1. One goal, small enough for a day, most under an hour.
2. You do the heavy lifting. The member does one or two actions.
3. Done is proven from HQ data, never from "I did it". Check the proof yourself.
4. Celebrate it, sized to the win (one line for small ones, a proper moment for the big ones), then unlock the next mission straight away with how long it takes.
5. One active mission at a time: the lowest numbered mission not yet done. If a later mission's proof appears first, mark that mission done straight away (it counts toward the progress bar), then keep the active mission where it is. Check every mission's proof each morning, so nothing stays open when its proof exists.

## Every day
1. The morning brief opens with one line: "Mission [n] of 19: [name]. Today: [the one action]."
2. When a mission's proof appears, mark it done, celebrate in one or two lines, and name the next mission with its time estimate.
3. Friday numbers include missions done this week.

## When they stall
If the active mission has not moved in 2 working days, make the next step smaller, not louder. One action they can do in 10 minutes, ready to go. Example: "Just one thing today: approve these 5 leads. I've done the rest." Never shame, never repeat the same nudge twice in a row.

## Never
1. Never mark a mission done without the proof in HQ.
2. Never skip a mission because the member says they did it elsewhere; ask them to show it, then record it.
3. Never run more than one mission's work in the background. The goal's fence still applies.
