# Palette and font library

Pack version: 2026-11-10.1500

Every palette below passed these checks: text on background at least 7 to 1, button text on main colour at least 4.5 to 1, main colour on background at least 3 to 1 (it is used for large headline words). Use only these values, or the student's own colours after the same checks.

## How to use it

1. Filter by the student's feel answer and light or dark choice, then by niche.
2. Offer 3 options from 3 different colour families, each with a different font.
3. Make it theirs: shift the main colour's hue by (sum of the character codes in the business name, mod 13, minus 6) degrees. Recheck all three contrast numbers after the shift. If any fails, use the unshifted colour.
4. "Show me 3 more": offer 3 options not shown before, again from different families.
5. Never mention palette names or colour codes to the student unless they ask.
