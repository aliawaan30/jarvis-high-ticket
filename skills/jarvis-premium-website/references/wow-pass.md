# The wow pass

The other checks make a site correct: responsive, readable, legal, consistent. This pass makes it memorable. Run it after the layout QA passes and before the member's review. A site that is correct but forgettable is not finished.

Learned 23 November 2026: a med spa preview passed every correctness check but felt safe: every section was text on one side and a visual on the other, the signature moment filled half the screen, the type was polite and the palette was the one every competitor uses.

## 1. Plan the wow (at check-in 1)

1. **One brand idea.** A single metaphor drawn from the name, the place or the result (for example Solenne, the sun: light that changes through the day). Every signature moment expresses it.
2. **One immersive signature moment** that takes over the whole screen and expresses the idea (for example the page's light rising from dawn to day as the visitor scrolls). Not half the screen, not a small card.
3. **At least two bold compositions** that break the usual grid: oversized type overlapping a full-bleed image, an asymmetric layout, a giant list, extreme scale contrast, type that fills the screen width.
4. **Distinctive palette and type.** Different from the top local competitors found in the research (if every competitor is beige and blush, do not be beige and blush). Say how it differs.
5. **Micro-interactions** that feel crafted: hover reveals (an image following the pointer over a list), magnetic main buttons, links whose underline draws, a custom cursor only where it adds something, smooth transitions. Phone versions use tap and swipe instead.

## 2. The five-second test

Open the site fresh at 1440 px and at 390 px. Within five seconds of the first screen, is there something that makes a visitor stop: dramatic type, a beautiful image, motion that reveals the idea? If not, the hero is not finished.

## 3. The critique loop (do it twice)

1. Take full-page screenshots at 1440 px and 390 px, plus screenshots of each signature moment mid-animation. Compare them with the level shown in references/quality-bar (the level, never the layout).
2. Critique them as a design award jury would: "Would this win Site of the Day? Is it distinctive for this niche, or could it belong to any business? What are the five weakest moments?" Be specific (which section, what is weak, what would fix it).
3. Fix the three most important problems.
4. Repeat once more. Then run the layout QA again, since changes can break responsiveness.

## 3b. Weak spots the critique often finds (from live builds)

- An empty column beside a form or a quiz: fill it with what happens next, hours and the phone number, or use one column where the result replaces the questions.
- A small, generic map or decoration that connects to nothing: give the map the area's real outline and large labels, or replace it with a panorama of the area with the names over it.
- A dark, muddy closing image: put the gradient only behind the text and choose a brighter shot.
- A sequence of a few stills that jumps: crossfade, or make a film between the first and last shots.

## 4. Guardrails

- Wow never costs readability, speed, accessibility or the rules of the niche. Every word stays real text; reduced motion still gets a complete, beautiful still version; phones get their own wow, never a broken version of the desktop one.
- Wow serves the sale: the main action stays obvious on every screen.
- Never copy an award site's design; take techniques, never identity.
