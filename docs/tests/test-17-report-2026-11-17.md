1. **Scope Jarvis to its own HQ from the first message.** The install should check Cross-app data access and refuse to touch any app it didn't create. Today a new agent defaults to "All workspace apps" and wrote to Jarvis HUD with "Update data" off. Also stop the background goal loop from acting unasked: it ran a lead hunt before the skill was installed, invented the Lone Star proposal, and posted "Nothing ready to launch. Stopping." at least 8 times.
2. **Make the package publish-safe.** Guard every `window` and `document` read at import time (the 500), and ship entry files that match the current Base44 router so the builder doesn't improvise. Stop config.jsonc from renaming the app to "Jarvis HUD".
3. **Fix the HUD to Jarvis handover.** Make "Copy for Jarvis" finish with a clear "Copied" or a visible error. Teach Jarvis to accept the auto-detected `AGENCY_HQ_HUD_KEY` and confirm it, not show a second form and call it blank. Find why talkSend returns 502 `conversation_failed` with a valid token and agent ID.
4. **Move Retell to its current API.** Test key and publish both call endpoints Retell retired (agent list, 31 Jul 2026, and agent versions, 20 Jul 2026). Speed up the first greeting to under 2 seconds.
5. **Use the student's country and real answers.** Set time zones and phone formats from the test answers (United States), not the browser (Asia/Karachi) or the package (Australia/Brisbane, +61). Show weekly call targets as weekly, not "Calls today 0/3". Keep check-ins under 80 words, say where they go, and give one next action.
