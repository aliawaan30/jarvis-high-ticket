# Jarvis Precall Followup

Reconstructed on the replacement Mac from the conversation; not a byte-identical recovery.

Read the latest approved offer brief: buyer, geography, problem, alternatives, mechanism, scope, price/currency, timeframe, proof, guarantee and CTA. Preserve these across assets. Separate the student's implementation offer from Blake's coaching offer. Without an approved offer, label the output a test specimen and state assumptions. Never invent proof, urgency, scarcity, customer quotations or performance. Use the buyer's actual language and objections when available; label inferred concerns. Save outputs when tools permit and link them. Report drafts, rendered assets, configured integrations and executed actions separately. A skill does not install tools or prove commercial performance.

This covers opted-in and booked-call nurture, not cold outreach. Use exact booking/timezone/status and contact preferences. Initial sequence: immediate logistics; a useful answer/demo if time permits; preparation reminder; imminent-call reminder where appropriate. Same-day bookings must not receive compressed multi-day nurture.
Return subject, body, channel, trigger, due time, linked asset, stop conditions and owner. SMS is concise; do not pretend automation is a personally typed message. Separate human rep tasks.
Before sending recheck booking state, schedule version, suppression, reply hold and already-sent status. Use contact/event/version/step idempotency keys. Reschedule/cancel invalidates old jobs. A question needing a human pauses persuasion and creates a task. Distinguish provider acceptance from delivery. Respect channel opt-outs; do not route around suppression through another channel.
The runtime needs working sender/domain or number, CRM/calendar, inbound replies, callbacks and failure handling. Verify tools/account availability rather than promise integration. Account for credit exhaustion and stale jobs; do not send late reminders after the meeting.
Test normal/same-day booking, reschedule, cancel, reply, opt-out, duplicate trigger, provider timeout and exhausted credits using designated test contacts. No live sending without authorisation. Report configured, executed and delivered separately.
